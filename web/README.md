# JobHunt Copilot: web

Next.js (App Router) front end. It talks to the FastAPI backend at `NEXT_PUBLIC_API_URL`.

```bash
npm install
NEXT_PUBLIC_API_URL=http://localhost:8000 npm run dev
```

Pages: login and register, profile editor, job feed, ranked matches with the reasoning panel, tracker board, preferences. See the repository README for the full picture.
